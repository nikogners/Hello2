# Hello2

A simple Hello World application with implementations in Python and Bash.

## Description

This project demonstrates basic "Hello World" applications in multiple languages. It includes configurable greeting functions that can greet different names.

## Usage

### Bash Version (Recommended)
Run the bash script:

```bash
./hello.sh
```

### Python Version
Run the Python application (requires Python 3.6+):

```bash
python3 hello.py
```

## Features

- Customizable greeting function
- Multiple language implementations
- Clean, documented code structure
- Simple command-line execution

## Requirements

- Bash shell (for hello.sh)
- Python 3.6 or higher (for hello.py, optional)

## Files

- `hello.sh` - Bash implementation (main executable)
- `hello.py` - Python implementation 
- `README.md` - This documentation file
